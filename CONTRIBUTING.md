# Contributing

Thanks for helping improve these tutorials.

- Open an issue for a bug, a wrong command, or an outdated price or model name.
- For a fix, open a pull request that changes one tutorial where possible.
- Run the commands in the tutorial's `README.md` before you submit. Say which steps you ran and which you did not.
- Save real output in `evidence/` when you change a step. Do not edit saved output by hand.
- Never commit API keys or `.env` files. Use `.env.example` for variable names.
- Keep the writing plain and specific. State limits and what was not tested.

By contributing you agree that your work is released under the MIT licence.
