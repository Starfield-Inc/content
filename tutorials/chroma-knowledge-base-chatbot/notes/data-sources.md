# Data sources

We use two public data sets.

1. Hourly water level readings from a national tide gauge network, downloaded as CSV files. Four harbours, 2019 to 2025.
2. Wind and pressure forecasts from a public weather service, fetched every 3 hours.

We did not scrape any website. Both sources publish files for reuse. Priya keeps the download dates in data/README.md so the numbers can be traced.
