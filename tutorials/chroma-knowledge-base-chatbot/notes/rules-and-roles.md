# Team rules

1. Every pull request needs one review from another member before it merges. The exception is the slides.
2. Maya merges to main. Nobody else pushes to main.
3. We stand up for five minutes at 10:00, 14:00 and 18:00 on both days.
4. If a task is blocked for more than 30 minutes, ask in the team chat.
5. Sleep is not optional. Everyone is offline from 01:00 to 07:00.
